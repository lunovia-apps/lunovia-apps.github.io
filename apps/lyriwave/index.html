About LyriWave

Import WAV or MP3 audio, edit lyrics, adjust timing on the timeline, customize text and backgrounds, preview the result, and export an MP4 lyric video.

Screenshots

Key features

  • Lyric editing

    Enter and edit multiple lines of lyrics.

  • Audio and waveform

    Import WAV or MP3 audio, play it back, seek, and view its waveform.

  • Timeline timing

    Adjust lyric timing by dragging and resizing clips, with snapping.

  • Typography and backgrounds

    Use bundled or imported fonts, position and style text, add outlines and shadows, and choose solid or image backgrounds.

  • Lyric animation

    Customize enter and exit animations for lyrics.

  • Real-time preview

    Preview the video while editing, with Play, Pause, Stop, and seeking controls.

  • Presets and Scene Templates

    Apply text-style presets, animation presets, and Scene Templates.

  • Projects and recovery

    Create, open, and save projects, use Undo and Redo, and recover from periodic snapshots after abnormal termination.

  • MP4 export

    Export H.264 video with AAC audio at 720p30, 1080p30, or 1080p60. Follow export progress or cancel an export.

Configure FFmpeg and ffprobe

FFmpeg and ffprobe are external requirements for audio import and MP4 export. They are not included with LyriWave.

  1. Separately obtain compatible versions of ffmpeg.exe and ffprobe.exe.
  2. Place both executables in the same folder.
  3. Open LyriWave and select Configure FFmpeg.
  4. Select ffmpeg.exe from that folder. LyriWave uses the folder for both media tools.
  5. Audio import and MP4 export can then use the configured tools.

These tools are third-party software, not developed, maintained, or distributed by Lunovia. If they are not configured, media operations fail with a configuration message; your saved project remains available.

Windows installation

LyriWave uses a Windows x64 installer. After installation, open LyriWave and configure FFmpeg before importing audio or exporting MP4.

Unsigned Windows installer

The initial Windows installer is unsigned. Windows Defender SmartScreen or other Windows security features may display a warning when it is launched. Obtain LyriWave only through official download links identified by Lunovia.

Known limitations

  • Audio

    Each project uses one imported song beginning at time zero. WAV and MP3 are validated; other formats are not guaranteed.

  • Project files and assets

    Keep the JSON project file and its adjacent assets/ folder together when moving or backing up a project. Save As to another folder is restricted when assets are present, and there is no general asset relinking picker. Restore missing files to their recorded locations, then check them again with asset validation.

  • Export

    Export uses temporary PNG frames and does not silently overwrite existing output files. A hard termination may leave a recent hidden partial output; older interrupted export sessions owned by the application are cleaned later.

  • Undo and recovery

    Undo history is limited to 100 snapshots, is not retained after restarting, and resets on audio import. Periodic recovery snapshots may not include the final edit before a hard crash.

  • Presets and Scene Templates

    Text-style presets do not include placement or imported fonts. Scene Templates do not include imported images or fonts, lyrics, audio, or timing, and apply the project background globally.

  • Updates

    Automatic update delivery is not provided.
